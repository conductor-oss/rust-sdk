# Agents SDK parity checklist

Source of truth is python-sdk (https://github.com/conductor-oss/python-sdk). Match its wire format and behaviour exactly; don't invent keys or endpoints. Java (`conductor-client-ai` in https://github.com/conductor-oss/java-sdk) is the second reference if you want a typed-language example.

Base path for all links below: `https://github.com/conductor-oss/python-sdk/blob/main/`

## A. Agent client

- Endpoints and methods: `src/conductor/client/agent_client.py`, `src/conductor/client/orkes/orkes_agent_client.py`
- Errors: `src/conductor/ai/agents/exceptions.py`
- Docs: `docs/agents/reference/client.md`

Register in the SDK's client factory, same as every other resource client.

## B. Agent definition + serializer

- Schema: `docs/agents/reference/agent-schema.json` (+ `agent-schema.md`, `agent-definition.md`)
- Definition: `src/conductor/ai/agents/agent.py`, `src/conductor/ai/agents/run_settings.py`
- Serializer: `src/conductor/ai/agents/config_serializer.py`
- Contract test: `tests/unit/ai/test_agent_schema_contract.py`, `tests/unit/ai/test_config_serializer.py`

## C. Tools

- `src/conductor/ai/agents/tool.py`
- Schema derivation: `src/conductor/ai/agents/_internal/schema_utils.py`
- Docs: `docs/agents/concepts/tools.md`
- Tests: `tests/unit/ai/test_tool.py`

## D. Guardrails / termination / handoffs / callbacks / memory

- `src/conductor/ai/agents/guardrail.py`
- `src/conductor/ai/agents/termination.py`
- `src/conductor/ai/agents/handoff.py`
- `src/conductor/ai/agents/callback.py`
- `src/conductor/ai/agents/memory.py`
- Docs: `docs/agents/concepts/guardrails.md`, `termination.md`, `callbacks.md`, `multi-agent.md`
- Tests: `tests/unit/ai/test_guardrail.py`

## E. Runtime

- Runtime: `src/conductor/ai/agents/runtime/runtime.py`
- Result/handle/stream/event types: `src/conductor/ai/agents/result.py`
- Worker registration: `src/conductor/ai/agents/runtime/worker_manager.py`, `tool_registry.py`
- Credentials: `src/conductor/ai/agents/runtime/credentials/`, `secret_injection.py`
- MCP discovery: `src/conductor/ai/agents/runtime/mcp_discovery.py`
- Docs: `docs/agents/concepts/deploy-serve-run.md`, `streaming-hitl.md`, `stateful.md`, `docs/agents/reference/runtime.md`
- Tests: `tests/unit/ai/test_runtime.py`, `test_runtime_metadata_registration.py`, `test_runtime_server_compile.py`, `test_agent_handle_join.py`

## F. Workflow DSL

- Task types: `src/conductor/client/workflow/task/task_type.py`
- Builders: `src/conductor/client/workflow/task/llm_tasks/`
- `start_agent` event action: java-sdk `EventHandler.StartAgent` (conductor-oss/java-sdk#168)

## G. Docs / examples / tests

- Docs: mirror `docs/agents/` structure.
- Examples: port `examples/agents/`, same numbering and names.
- Tests: mirror `tests/unit/ai/` and `tests/integration/test_agentic_workflows.py`.
- E2E CI: copy `.github/workflows/agent-e2e.yml` (java-sdk has the same).

## Done when

Same agent in this SDK and in Python produces identical `agentConfig`; runs end to end against a live server with HITL and streaming; docs, examples, and tests mirror the above.
